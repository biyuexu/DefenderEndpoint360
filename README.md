# DefenderEndpoint360 | Agentic Defense for the Next Gen AI Powered SOC

**Defender Endpoint 360 is a multi-agent Security Copilot solution built on a hierarchical parent-child agent architecture**, transforming endpoint investigation from a series of manual, disconnected steps into a** coordinated, evidence-driven agentic workflow**—where specialized agents work together to investigate, correlate, and surface actionable findings.

Unlike Project Perception, which orchestrates specialized agents across broader security operations workflows, **Defender Endpoint 360 is purpose-built to go deep on a single endpoint**. It brings together process, file, registry, network, user, and threat context to build a comprehensive picture of what happened—**essentially acting as a Tier 1 or Tier 2 SOC analyst that investigates the endpoint for us**. And it’s on-demand by design: invoke the parent agent when an endpoint needs investigation, and let it orchestrate the investigation, connect the evidence, and surface the findings—without requiring an analyst to manually piece together the story.

Each child agent examines a specific dimension of the endpoint investigation using the appropriate security skills and evidence sources. The parent agent then correlates those findings into a consolidated investigation view that helps the analyst understand:

- What happened?
- What executed?
- What is suspicious?
- What other activity is related?
- What does threat intelligence tell us?
- What evidence supports the assessment?
- What should the analyst investigate next?

The goal is not to replace the SOC analyst. **It is to give the analyst an AI investigation team that can perform the repetitive evidence-gathering and correlation work in parallel, while keeping the analyst in control of the investigation and final decision.**
